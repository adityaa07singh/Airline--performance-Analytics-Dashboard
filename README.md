# ✈️ Airline Performance Analytics Dashboard

## 📌 Project Overview
This project analyzes airline performance using SQL and Tableau. The dashboard provides insights into flight volume, arrival delays, departure delays, cancellation rates, and average flight distance across different airlines.

The objective of this project is to identify operational trends, evaluate airline performance, and generate actionable business insights through data visualization.

---

## 🛠️ Tools & Technologies
- Tableau
- PostgreSQL
- SQL
- Data Visualization
- Data Analysis

---

## 📊 Dataset Information
The dataset contains airline operational records, including:

- Flight Number
- Airline
- Origin Airport
- Destination Airport
- Arrival Delay
- Departure Delay
- Cancellation Status
- Flight Distance

---

## 📈 Dashboard Features

### 1️⃣ Flight Count by Airline
Displays the total number of flights operated by each airline.

### 2️⃣ Average Arrival Delay by Airline
Compares airlines based on average arrival delays.

### 3️⃣ Average Departure Delay by Airline
Measures departure punctuality across airlines.

### 4️⃣ Cancellation Rate by Airline
Shows the percentage of cancelled flights for each airline.

### 5️⃣ Average Distance by Airline
Compares the average distance travelled by airlines.

---

## 🔍 Key Insights

- Identified airlines operating the highest number of flights.
- Analyzed airline punctuality using arrival and departure delays.
- Evaluated cancellation performance across airlines.
- Compared average travel distances between airlines.
- Highlighted performance differences among carriers.
