# Airline Performance Analytics Dashboard

## Project Overview
This project analyzes airline performance using Tableau and PostgreSQL. The dashboard provides insights into flight volume, arrival delays, departure delays, cancellation rates, and average flight distance across different airlines.

## Tools Used
- Tableau
- PostgreSQL
- SQL
- Data Visualization

## Dataset
The dataset contains airline operational data including:
- Flight Number
- Airline
- Origin Airport
- Destination Airport
- Arrival Delay
- Departure Delay
- Cancellation Status
- Distance

## Dashboard Features

### 1. Flight Count by Airline
Analyzes the total number of flights operated by each airline.

### 2. Average Arrival Delay by Airline
Compares airline performance based on average arrival delay.

### 3. Average Departure Delay by Airline
Measures departure punctuality across airlines.

### 4. Cancellation Rate by Airline
Shows the percentage of cancelled flights for each airline.

### 5. Average Distance by Airline
Compares average travel distance covered by airlines.

## Key Insights
- Identified airlines with the highest flight volume.
- Analyzed airlines with the highest arrival and departure delays.
- Evaluated airline cancellation performance.
- Compared average flight distances among airlines.
